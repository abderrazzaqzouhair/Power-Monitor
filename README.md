# 📱 Power Monitor - Suivi et optimisation de la consommation d'énergie

## 📌 Description
Une application mobile pour surveiller et optimiser la consommation d'énergie des ménages.
- **Problématique** : Hausse des coûts énergétiques et impact environnemental.
- **Solution** : Outils intuitifs (suivi en temps réel, visualisation graphiques, conseils personnalisés).

## ✨ Fonctionnalités
- 📊 Visualisation des données de consommation (jour/mois).
- 🔔 Alertes en cas de dépassement des seuils.
- 💡 Conseils pour réduire sa facture énergétique.
- 🌍 Comparaison avec des foyers similaires.

## 🛠️ Technologies
- **Frontend** : Kotlin (Android).
- **Backend** : Firebase.
- **Base de données** : Firebase Firestore..
